# Топоотчет

Веб-приложение для специалиста по земельно-имущественным отношениям. Принимает фото, скан или PDF топографической съемки, находит высотные отметки и реквизиты плана, дает сверить их с листом и формирует отчет в DOCX и PDF.

Файлы обрабатываются на компьютере, где запущено приложение, и не передаются во внешние сервисы. Результаты разбора хранятся только в оперативной памяти до перезапуска.

## Что умеет

- Читает PDF, JPEG, PNG и TIFF до 60 МБ. В PDF обрабатываются первые 5 страниц.
- Цифровой PDF читает из текстового слоя без потери точности. Скан и фото распознает через Tesseract.
- Выравнивает лист на фото и разворачивает изображение, снятое боком или вверх ногами.
- Находит кадастровые номера, адрес, масштаб, сечение рельефа, системы высот и координат, дату съемки, площадь, исполнителя.
- Отделяет отметки от длин линий, площадей, дат и координат сетки, а сомнительные значения исключает из расчета и показывает специалисту.
- Считает наименьшую, наибольшую, среднюю отметку, перепад, средний и наибольший уклон, направление понижения.
- Строит схему высот по отметкам. Вне контура точек поверхность не достраивается.
- Показывает каждую отметку на листе: значение можно исправить, подтвердить, исключить или добавить новое.

## Точность

Измерено на тестовом листе из папки `samples`. Это синтетический план с известными значениями: 43 отметки, горизонтали, сетка, длины границ участка. На реальных съемках результат будет другим, поэтому отчет нужно сверять с листом.

| Источник | Найдено верно | Ошибочных значений среди включенных | На сверку |
|---|---|---|---|
| Цифровой PDF | 43 из 43 | 0 | 0 |
| Имитация фото A3 (перспектива, тень, шум, 12 Мп) | 40 из 43 | 0 | 11 |

Расчет уклона проверен на плоскостях с известным наклоном. Для тестового листа наибольший уклон между точками не превышает истинных 13%.

## Запуск на Windows

1. Установите [Python 3.10+](https://www.python.org/downloads/) с опцией Add Python to PATH.
2. Установите [Tesseract](https://github.com/UB-Mannheim/tesseract/wiki) и отметьте русский язык (Additional language data → Russian).
3. Дважды нажмите `start.bat`. Откроется `http://127.0.0.1:8000`.

Если Tesseract установлен не в `C:\Program Files\Tesseract-OCR`, укажите путь в переменной `TESSERACT_CMD`.

## Запуск на Linux и macOS

```bash
sudo apt install tesseract-ocr tesseract-ocr-rus   # macOS: brew install tesseract tesseract-lang
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

## Запуск в Docker

```bash
docker build -t topo-report .
docker run --rm -p 127.0.0.1:8000:8000 topo-report
```

Для работы по сети укажите адрес в `TOPO_ALLOWED_HOSTS` и защитите доступ: в приложении нет входа по паролю, а документы могут содержать персональные данные.

## Как пользоваться

1. Загрузите файл или откройте тестовый лист.
2. Проверьте реквизиты в штампе. Что не найдено, отмечено как «не найдено», поле можно заполнить вручную.
3. На вкладке «Сверить» пройдите отметки: Enter подтверждает значение и переходит к следующему.
4. Если отметка пропущена, нажмите «Добавить отметку» и укажите место на листе.
5. Для уклона нужны масштаб и разрешение. У PDF разрешение известно, у фото его можно указать только для ровного листа без перспективы.
6. Скачайте отчет в DOCX или PDF.

## Ограничения

- Отчет не заменяет материалы инженерных изысканий и не является документом геодезической организации.
- Подписи, повернутые под углом, на сканах и фото читаются хуже: горизонтальные отметки распознаются надежнее подписей горизонталей.
- Отметки определяются по подписям. Горизонтали без подписей и условные знаки не векторизуются.
- Направление склона рассчитано в предположении, что верх листа — север.
- На фото масштаб не определяется автоматически. Уклон там считается по указанному dpi и верен только при отсутствии искажений.
- Уверенность распознавания у Tesseract иногда занижена даже для верных чисел, поэтому часть правильных отметок попадает на сверку.

## Разработка

```bash
pip install -r requirements-dev.txt
python -m pytest
python samples/generate_sample.py   # пересоздать тестовый лист
```

Структура: `app/loader.py` читает файлы, `app/ocr.py` распознает изображение, `app/extract.py` находит отметки и реквизиты, `app/heights.py` считает показатели, `app/report.py` собирает отчеты, `app/main.py` содержит API, `app/static` — интерфейс.

Шрифты PT Sans и PT Sans Narrow распространяются по лицензии SIL OFL 1.1.
